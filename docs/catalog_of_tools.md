# Catalog Of Tools

This catalog is a code-sourced inventory of Daylily tool integrations. A row is included only when the tool is present in Snakemake rules, conda env YAMLs, profile config, supporting-file config, packaged resources, or scripts invoked by rules or tests. Web lookup is used only to enrich upstream links, publication links, or clinical-use notes for tools that are already present in this repository.

`/fsx/data/**` entries mean the repo references those paths in config, tests, or docs; they are not treated here as locally bundled data unless also present under `.test_data/**` or `resources/**`.
