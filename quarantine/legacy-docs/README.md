# Quarantined Legacy Documentation

This directory preserves the documentation surface that existed before the 2026-05-26 DayOA documentation rebuild.

The files are intentionally kept under their original path prefixes:

- `root/` contains former top-level repository documentation such as the old `README.md`, historical plans, reports, and run notes.
- `docs/` contains the former `docs/` tree, excluding `docs/plans/`.

`docs/plans/` remains in the active repository documentation tree because plan and ledger files are durable execution records, not legacy narrative documentation.

Use this quarantine as historical evidence only. New operator-facing and integration-facing documentation lives in the regenerated repository root `README.md` and active `docs/` tree.
